# Spectroscopy



Kansiossa pio-versio on se versio (PIO\&DMA), jota näytin yliopistolla. Picon osalta siellä on lähdekoodi, valmis uf2-tiedosto ja Python-koodi (graph\_pio.py). Picossa on nyt tämä versio sisällä. Lisäksi tekoälyllä tehty testaamaton versio (ilx554a\_pio.ino), jonka pitäisi olla samanlainen ja toimia suoraan Arduino IDE:ssä.



Kansiossa ide-versio on alkuperäinen yksinkertaisempi versio, joka toimii suoraan Arduino IDE:llä (ilx554a.ino) ja sen kanssa toimiva Python-koodi (graph\_ide.py).
